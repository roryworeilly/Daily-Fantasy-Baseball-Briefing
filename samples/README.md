# Samples

This folder contains example outputs generated by the Fantasy Baseball Daily Briefing app.

| File | Description |
|---|---|
| `Daily Briefing Sample.html` | Open in any browser to see a full generated briefing with all tabs: matchup scoring, lineup lab, waiver wire, Statcast signals, season simulation, and trade targets. |

> **Note:** Player names, scores, and statistics in sample files are real data from a live season and are included for demonstration purposes only.
